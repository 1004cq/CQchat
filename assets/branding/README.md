# CQchat Logo

CQchat 的 Logo 方向围绕三个核心特征展开：**附近连接、聊天沟通、端到端隐私**。

## 推荐主标

`cqchat-logo.png`（优化后的 B 版，源文件为 `cqchat-logo-b-refined.png`）

图形将两个重叠的聊天气泡、三个 Mesh 节点和中心锁合并为一个符号。优化版减少了内部杂线，强化了负空间和中心锁的轮廓，使它在 App 图标和 favicon 尺寸下仍然清晰：

- 重叠气泡环：表达附近聊天与双向沟通
- 三个连接节点：表达蓝牙 Mesh / 附近设备互联
- 中心锁：表达本地密钥与加密隐私
- 蓝色 + 青色：兼顾可靠、安全与轻量科技感

## 备选方案

- `cqchat-logo-a.png`：更直接地表达“聊天 + 节点 + 钥匙孔”，适合需要强化功能解释的页面。
- `cqchat-logo-b.png`：原始 B 版，保留作为设计过程备选。
- `cqchat-logo-c.png`：更强调“多设备连接”，风格更轻，但聊天和加密识别度相对弱。

## 建议使用

- App 图标、README 顶部、网站 favicon：优先使用优化后的 B 版主标 `cqchat-logo.png`。
- Logo 周围保留至少图形高度 1/5 的安全距离。
- 深色背景优先使用原始透明 PNG；浅色背景可放在白色或极浅蓝色底上。
- 不建议在小尺寸下叠加 `CQchat` 字样；文字版 Logo 应另行制作精确字标。
