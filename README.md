# CQchat

离线加密聊天。用蓝牙或 WiFi 热点，不用网，不要账号，不要服务器。

Offline encrypted chat over Bluetooth mesh and WiFi hotspot.

## 是什么

CQchat 是给附近的人用的。手机之间直接传消息，服务器看不到明文。

- 没有账号、手机号、邮箱
- 没有自建服务器
- 私聊端到端加密
- 关网也能聊

## 怎么传

| 方式 | 用法 | 适合 |
|---|---|---|
| 蓝牙 Mesh | 自动发现附近设备，多跳中继 | 关网、随便聊、不用设置 |
| WiFi 热点 | 一台开热点，其他人连上 | 传图、语音、一群人在同一地方 |

优先走蓝牙。同一热点或局域网可用时，切到 WiFi 传更大的内容。

明确不做：推送服务器、好友系统、朋友圈、通话。

## 和在线 IM 的区别

这不是 imimchat。那边有账号、服务器、离线推送和通话。CQchat 只做附近、断网、加密。
