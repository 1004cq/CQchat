# CQchat

离线加密聊天。用蓝牙或 WiFi 热点，不用网，不要账号，不要服务器。

Offline encrypted chat over Bluetooth mesh and WiFi hotspot.

## 是什么

CQchat 是给附近的人用的。手机之间直接传消息，服务器看不到明文。

- 没有账号、手机号、邮箱
- 没有自建服务器
- 私聊端到端加密
- 关网也能聊

## 怎么传

| 方式 | 用法 | 适合 |
|---|---|---|
| 蓝牙 Mesh | 自动发现附近设备，多跳中继 | 关网、随便聊、不用设置 |
| WiFi 热点 | 一台开热点，其他人连上 | 传图、语音、一群人在同一地方 |

优先走蓝牙。同一热点或局域网可用时，切到 WiFi 传更大的内容。

## 身份

首次启动在本地生成密钥对，不注册、不上传。

- 长期身份：X25519 静态密钥，放 Keychain / Keystore
- 显示名：昵称，可随时改，不参与认证
- 对方识别：公钥指纹（前 8 字节），用户可以对着二维码核对
- 没有用户 ID、手机号、邮箱
- 未扫二维码的对方标「未验证」。扫过才标「已验证」

## 加密

私聊必须端到端。中间设备只能看到密文。蓝牙和热点用同一套会话密钥，不重新握手。

- 密钥协商：Noise XX（X25519 + ChaCha20-Poly1305），或等价的 X25519 封装
- 每条消息带 `msg_id` 和递增 nonce，防重放
- 活会话有前向安全；离线代传的信只封装，不保证前向安全
- 公频：签名广播，附近的人都能看，不当成私密
- 不做服务端解密，也没有服务端

## 防扫描与拦截

扫描器解不开明文，但能看到设备在、什么时候发包、包有多大。要少让它认出你、少让中间人改包。

- 广播标识轮换：蓝牙广播里不一直用同一个 8 字节 ID，每几分钟换临时标识。只有已建会话的对端能关联回长期公钥
- 广播最小化：发现包只放临时标识和协议版本。昵称和长期公钥不在明文广播里一直挂着
- 防重放：对端拒绝旧 nonce 或重复 `msg_id`。改一个字节就解密失败
- 热点不额外泄露：mDNS 不放昵称和长期公钥。TCP 上只送已加密信封。热点密码不当端到端
- 降低可追踪性：发包加随机延迟，密集时少跳。可选填充到固定长度

杀进程后仍然可能被扫到有设备，不承诺完全隐身。

## 包格式

自定义二进制包，不走 JSON。蓝牙带宽低，包要小。

| 字段 | 说明 |
|---|---|
| version | 协议版本 |
| type | 广播 / 私聊 / 确认 / 同步 |
| sender | 发送者指纹或临时标识 |
| msg_id | 去重用 |
| ttl | 剩余跳数，起始 7 |
| payload | 密文或签名广播 |

超过 MTU 的内容分片。接收端按 msg_id 拼回。

## 蓝牙 Mesh

- BLE，每台设备同时做 central 和 peripheral
- 发现：广播临时标识，不广播长期公钥
- 路由：控制洪泛，不是每个包都无限转发
- TTL 起始 7，每跳减 1，到 0 丢弃
- 去重：LRU，按 sender + msg_id，保留约 5 分钟
- 密集网络降低广播跳数，避免风暴
- 对方不在范围：本地队列，或交给路过的设备代传

直连约 10–50 米。远离全靠别人手机中继，人少就传不远。

## WiFi 热点

蓝牙不够带宽时再用。

- 一台开 SoftAP，其他人连上；或大家已在同一局域网
- 发现：mDNS / Bonjour，只找到对方本地 IP
- 传输：本地 TCP，负载仍是上面的加密信封
- 不做真正多跳。热点主机更耗电，也不是自动的

蓝牙负责发现和小消息，WiFi 负责图、语音、文件。失败立刻退回蓝牙，用同一个 `msg_id` 重发。

## 通知

只有本地通知，没有 APNs / FCM。

- App 还在后台、蓝牙还能扫到时：附近有人、私聊到达
- 杀进程、不在蓝牙范围：不会有系统弹窗
- 附近人通知做冷却，避免刷屏

## 平台限制

- iOS：CoreBluetooth。后台扫描和广播有限制，不能保证锁屏后一直在线
- Android：扫蓝牙通常要定位权限。后台要前台服务，否则系统会杀
- 两端协议必须一致，不能各写各的

## 状态

早期项目。仓库已建，客户端还没开始写。

计划第一期：

- 本地生成密钥，不注册
- 蓝牙发现附近的人（临时标识轮换）
- 公频 + 加密私聊
- 二维码核对身份
- 本地通知（App 还在后台时）

第二期再加 WiFi 热点通道。

明确不做：推送服务器、好友系统、朋友圈、通话、Nostr、自建中继服务器。

## 和在线 IM 的区别

这不是 imimchat。那边有账号、服务器、离线推送和通话。CQchat 只做附近、断网、加密。
