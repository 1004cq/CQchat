# 落地顺序

与优化方案一致。当前仓库已有最小客户端；后续严格按阶段加能力，每阶段同步规范 + 向量 + 两端。

| 阶段 | 内容 | 状态 |
|---|---|---|
| 0 | 冻结协议边界、威胁模型、状态机、向量 | 进行中（v0.1 文档） |
| 1 | BLE 单跳：密钥、扫码、私聊文字、重放、重启后安全重握手 | 基本有；按 v0.1 收状态机/指纹 |
| 2 | ACK、重试、队列、去重、乱序分片、可解释状态 | 部分有 |
| 3 | 有限 TTL Mesh、拥塞、中继配额 | 未做稳 |
| 4 | Wi‑Fi + 媒体 + 回退（断点续传偏后） | 雏形 |
| 5 | 分平台后台与附近模式/隐私 UX | 雏形 |
| 6 | Fuzz、故障注入、第三方审查 | 未做 |

**原则：** 单跳身份/握手/重放/确认/队列不稳，不做多跳与大文件放大问题。
