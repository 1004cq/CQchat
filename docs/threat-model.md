# CQchat 威胁模型（v0.1）

## 产品是什么

附近设备之间、无账号、无服务器、无公网依赖的加密消息工具。  
**不是**「杀进程后仍可靠的无线基础设施」，也 **不是** 隐身通信系统。

## 防御目标（v0.1）

| 目标 | v0.1 水平 |
|---|---|
| 内容机密性（私聊） | Noise XX 会话加密；中继不可读正文 |
| 身份可核对 | Ed25519 指纹当面扫码 →「已验证」 |
| 公频完整性 | Ed25519 签名；UI 标「公开消息」 |
| 重放 | 拒绝重复 `msg_id` 与已用 Noise 计数器 |
| 发现不可链接（弱） | temp_id 轮换；广播不含长期公钥/昵称 |

## 明确不防御 / 弱防御

| 威胁 | 说明 |
|---|---|
| 全局流量分析 | 附近射频观察者仍可见时间、体量、图样 |
| 杀进程后投递 | 不承诺；无推送服务器 |
| 隐身 | 杀进程后设备仍可能被扫到；见 README |
| 恶意中继丢弃/延迟 | 尽力投递；靠 TTL/过期/重试，无全局可靠性 |
| 设备丢失未加密备份 | 本地 Keychain/Keystore 外的聊天记录保护因平台而异；v0.1 无远程擦除 |
| 物理靠近攻击者 | 可不断发现/连接尝试；需用户关「附近模式」 |
| 用户扫码后身份暴露 | **预期行为**：扫码即建立可识别长期关系 |

## 攻击者画像

1. **被动监听**：捕获 BLE/Wi‑Fi 帧 → 应无法读私聊明文；可做元数据推断。
2. **主动伪造设备**：假 temp_id / 假握手 → 未验证 UI；无私钥无法通过扫码验证。
3. **恶意中继**：丢包、重放、灌大包 → 去重、TTL、配额、未验证大文件默认限制。
4. **重放**：旧密文重放 → msg_id + nonce 拒绝。
5. **资源耗尽**：分片炸弹、大媒体 → 上限与自动丢弃；低电量优先文字/ACK。

## 隐私拆解（取舍）

| 维度 | v0.1 取舍 |
|---|---|
| 内容机密性 | 优先（私聊） |
| 身份不可链接 | 发现阶段尽量；扫码后放弃对该联系人的不可链接 |
| 元数据保护 | 弱；不承诺抗流量分析 |
| 可用性 | 前台/附近模式开启时优先；后台降级 |
| 抗审查 | 无中心服务器；仍受本地射频与系统权限约束 |

## 用户可见承诺话术

- 开启附近模式后：尽量发现与连接；系统允许时后台恢复。
- 关闭附近模式 / 杀进程 / 出范围：不保证收发。
- 「已送达」仅表示对端 ACK，不是已读。
